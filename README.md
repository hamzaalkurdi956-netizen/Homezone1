# HomeZone – المتجر ولوحة الإدارة

متجر أجهزة كهربائية صغيرة بثمانية أقسام ZONE، وسلة، وطلبات تصل إلى لوحة الإدارة مباشرة.
المشروع **بلا أي حزم خارجية**: يحتاج **Node.js 22.13 أو أحدث** فقط، ولا يحتاج `npm install`.

## التشغيل على جهازك

```bash
ADMIN_PASSWORD="كلمة-مرور-قوية" npm start
```

افتح http://localhost:3000 للمتجر، و http://localhost:3000/admin للوحة الإدارة.
إن لم تضع `ADMIN_PASSWORD` يولّد الخادم كلمة مرور مؤقتة ويطبعها مرة واحدة في الطرفية.

عند أول تشغيل تُدخَل **24 منتجًا تجريبيًا** وكود `WELCOME10`. احذفها من لوحة الإدارة وأضف منتجاتك.

## ما في اللوحة

| التبويب | الوظيفة |
|---|---|
| ORDERS ZONE | طلبات الزبائن (الاسم، الرقم، العنوان، الأجهزة)، تغيير الحالة، طلب يدوي، تصدير CSV، وعدّاد للطلبات الجديدة |
| STOCK ZONE | إضافة المنتجات وتعديلها وحذفها وتعديل السعر مباشرة، مع صورة وفيديو وشرح لكل منتج |
| CODE ZONE | أكواد الخصم (نسبة أو مبلغ ثابت وحد أدنى للطلب) |
| WATCH ZONE | فيديوهات ترويجية (ملف أو رابط) تظهر في المتجر |
| PARTNERS ZONE | شركاء النجاح وشعاراتهم وروابطهم |
| SETUP ZONE | حد التوصيل المجاني ورسومه وشريط الإعلان |

## النشر على الإنترنت

الخادم يحتاج **قرصًا دائمًا** لمجلد البيانات (`DATA_DIR`)، لأن فيه قاعدة البيانات والصور والفيديوهات.

**Docker (على أي استضافة):**
```bash
docker build -t homezone .
docker run -d -p 3000:3000 -v homezone-data:/data -e ADMIN_PASSWORD="كلمة-مرور-قوية" homezone
```

**خادم VPS عادي:** ثبّت Node 22 ثم شغّل `npm start` تحت `pm2` أو `systemd`، وضع خلفه Nginx أو Caddy لشهادة HTTPS.

**منصات مثل Render وRailway وFly.io:** انشر المشروع من Dockerfile، وأضف **Volume/Disk** مربوطًا بالمسار `/data`، وعرّف `ADMIN_PASSWORD`.

> لا تنشر على منصة بلا قرص دائم (مثل الخطط المجانية التي تمسح الملفات)، وإلا ضاعت الطلبات والصور عند كل إعادة تشغيل.

## المتغيرات

| المتغير | المعنى | الافتراضي |
|---|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة. غيّرها بتغيير هذا المتغير وإعادة التشغيل | تُولَّد مرة واحدة |
| `PORT` | منفذ الخادم | 3000 |
| `DATA_DIR` | مجلد البيانات | `./data` |
| `TRUST_PROXY` | ضع `1` إذا كان الموقع خلف وسيط HTTPS واحد موثوق. بدونه تُحسب كل الزيارات من عنوان الوسيط، وبوجوده دون وسيط يمكن تزوير العنوان | `0` (وفي Docker `1`) |
| `MAX_VIDEO_MB` | أقصى حجم لفيديو مرفوع | 100 |

يمكنك وضعها في ملف `.env` بجانب `server.js` (انظر `.env.example`).

## النسخ الاحتياطي

انسخ مجلد `DATA_DIR` بالكامل (يحتوي `homezone.db` و`uploads/`). أوقف الخادم لحظة النسخ، أو انسخ والخادم يعمل ثم تحقق من الملف.

## الأمان

- الطلبات والأسماء والأرقام لا تُعرض إلا بعد تسجيل دخول الإدارة. الأسعار والمجاميع تُحسب في الخادم ولا يثق بما يرسله المتصفح.
- بعد 8 محاولات دخول خاطئة من العنوان نفسه يُقفل الدخول 15 دقيقة.
- الملفات المرفوعة تُفحص بمحتواها (png وjpg وwebp وgif وmp4 وwebm فقط)، ولا تُقبل SVG.
- شغّل الموقع خلف HTTPS دائمًا.

## ما لا يفعله المشروع الآن

- لا يوجد دفع إلكتروني: الدفع عند الاستلام.
- لا يرسل إشعارًا بالبريد أو واتساب عند وصول طلب؛ يظهر عدّاد في لوحة الإدارة ويتحدث كل 30 ثانية.
- خادم واحد وقاعدة SQLite: تكفي لمتجر صغير ومتوسط الزيارات.

## واتساب

من لوحة الإدارة ← الإعدادات ← «رقم واتساب المتجر» (مع رمز الدولة، مثل 962791234567).
- بعد تأكيد الطلب يظهر للزبون زر يفتح واتساب برسالة جاهزة فيها تفاصيل طلبه إلى رقم المتجر.
- في كل طلب بلوحة الإدارة زر «واتساب» يفتح محادثة مع الزبون برسالة تأكيد جاهزة.
- الإرسال يتم بضغطة من المستخدم نفسه (روابط wa.me). الإرسال التلقائي الكامل دون ضغط يحتاج WhatsApp Business API المدفوع، وهو غير مضاف.
